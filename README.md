# furkaneskil.com

My personal site: a one-screen home page and a small blog.

- [Astro](https://astro.build), static output
- Blog posts are Markdown files in an Astro content collection
- Code blocks are highlighted at build time with [Shiki](https://shiki.style), using a custom theme made from the palette of my terminal
- Hosted on Cloudflare, with a strict Content-Security-Policy set in `public/_headers`
